## Implemented changes

- Installed Flutter 3.50.0 / Dart 3.14.0 through FVM and selected it globally. Updated the shell's stale SDK path to FVM's default link. Pinned the Flutter workspaces and required stable SDK versions.
- Prepared oh_my_flutter 0.29.0. Migrated standalone Material/Cupertino imports, localization ownership, consumer snippets, example dependencies and stable CI channels. `material_ui` is a runtime dependency because existing native-selection UI and Material color handling need it; neutral color utilities now import only their actual dependencies.
- Honored iOS Reduce Motion independently of Disable Animations at all 11 existing package motion-policy sites in nine files; updated Mateo, Cataquí, and generated Lottie/icon policies too. Preserved the two independent values in captured Mateo overlays.
- Preserved Flutter 3.50's soft-hyphen policy through TextMotion, Morph and Contour. Added optional `MorphTextProperties.hyphens` with the standard manual default; updated text capture, measurement, rendering and identity where the observable text choice matters.
- Migrated native context-menu identity to `ContextMenuButtonKind`. This does **not** add a Translate command that EditableText does not currently supply.
- Removed Contour shader early returns alongside samplers, the pattern Flutter 3.50 diagnoses as a Windows shader-compilation crash hazard. A compiler regression fails on the original shader and passes for all five backends after the control-flow-only change.
- Updated Android to AGP 9.3.1, Gradle 9.5.0 and Kotlin 2.4.20. Enabled the package example's modern AGP DSL only after real builds/tests/lint proved compatibility; Cataquí now also uses the modern DSL and built-in Kotlin after a separate staging APK verified its plugins and a freshly compiled MainActivity. Kept API 36 defaults because the broader API 37 default change was reverted upstream.
- Added the required iOS registrar `engineIdentifier` to the native test spy. The original spy fails against the new protocol; the current spy and seven native registration tests pass.
- Added Android email-code autofill beside the generic one-time-code hint in Cataquí, retaining the existing iOS hint.
- Replaced the removed strict-raw-types analyzer option with its no_raw_types lint, preserving strict casts and inference.
- Prepared dotdart 0.12.0, regenerated canonical consumer assets, and updated consumer version constraints. Updated only the Cataquí generator/library bounds needed to resolve and generate on Dart 3.14; updated the Melos launcher lock dependency that fixed its Dart 3.14 startup failure.

# Flutter3.50 framework and design-library audit

Review date: 2026-11-13. Scope: oh_my_flutter, Mateo mobile Flutter, and Cataqui Mobile.
